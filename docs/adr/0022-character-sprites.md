# 0022: 裁判型の立ち絵を透過 PNG のキャラクターにし、場面で表情を変える

- 日付: 2026-10-03
- 状態: 採用

## 背景

裁判型の法廷(ADR 0015・0017)は、仮素材の SVG の立ち絵と単色の背景で描いていた。
オリジナルのキャラクター画像(JPEG・単色の背景)が用意できたので、法廷の画面を見栄えのするものにしたい。

## 決定

- 裁判型の法廷に立つ 3 人は、どの事件でも同じ顔ぶれが演じる
  - 裁判官: アヤ(`aya_standard`)
  - 検察官(プレイヤー): タマ(`tama_standard`・つきつけるときの `tama_igiari`)
  - 被告: カブ(`cub_standard`・矛盾を突かれたときの `cub_nervous`・有罪のあとの `cub_lose`)
- 元画像は `frontend/.work/`(git 管理外)に置き、`frontend/scripts/cutout_sprites.py` で背景を抜いた透過 PNG を
  `frontend/public/assets/characters/` に出力してコミットする
  - 背景は画像の縁からの塗りつぶし(背景色からの距離)で求め、輪郭はなだらかに透かす。長辺は 1100px に縮める
- 立ち絵の選び方は `src/assets/manifest.ts` の `TRIAL_SPRITES`・`trialSprite` に寄せ、表情は `CourtShot` の `pose` で渡す
  - 表情の決め方は `src/lib/pose.ts`(つきつける = `igiari`、証拠品をつきつけられた被告 = `nervous`。ただし `trap` の組では動じない)
  - 判決の場面の被告の台詞は `lose`(`verdictScript` の台詞に `pose` を持たせる)
- 法廷の背景・机・台詞の枠は CSS で描き直す(席ごとの壁・紋章・スポットライト・つきつけるときの集中線。すべてオリジナルの意匠)

## 理由

- 事件ごとに立ち絵を作ることはできないので、法廷の「役者」を固定にしたほうが見た目が揃う
- 元画像から作り直せる手順を残しておけば、画像を差し替えたときも同じ品質で透過できる
- 表情は表示だけの派生状態で、ゲームの判定には使わない(勝敗・ペナルティはこれまでどおりイベントログから)

## 影響

- LLM が生成した事件でも、被告はカブ・検察官はタマの立ち絵になる(名札は事件の人物名のまま)
- 応答のストリーミング中は組の強さを伏せているので、つきつけられた被告はいったん困惑し、`trap` だった場合は応答のあと通常の表情に戻る
- ディベート画面の裁判長もアヤの立ち絵になる。肯定側・否定側は仮素材の SVG のまま(使わなくなった証人の SVG は消す)
