# 0023: 効果音を Web Audio API で合成し、BGM を流す

- 日付: 2026-10-04
- 状態: 採用

## 背景

法廷の場面(ADR 0015・0017・0022)は絵と文字だけで、音がなかった。
台詞の文字送りと、証拠品をつきつける瞬間に効果音を付けて、法廷バトルの手ごたえを出したい。
あわせて、オリジナルの BGM(`frontend/.work/bgm.mp3`。約 98 秒・192kbps・2.6MB)を流したい。

## 決定

- 効果音は音のファイルを使わず、Web Audio API でその場で合成する(`src/lib/sound.ts`)
  - 文字送りの音(`playBlip`): 矩形波の短い音(約 35ms)。高さを少しずつ揺らす
  - つきつける音(`playSlam`): 帯域を絞った短いノイズ(はじける音)と、急に下がる低い音(打撃音)を重ねる
- 文字送りの音は、台詞を打ち出す間に鳴らす(`useTypingSound`。`Typewriter` と `useDialogue` から使う)
  - 開廷の場面・証言の読み上げ・検察官の台詞・被告の応答・ディベートの発言のすべてで鳴る
  - 最短 55ms おき(`BLIP_INTERVAL_MS`)。空白・句読点・記号だけが出たときは鳴らさない(間を作る)
  - 全文を一度に出したとき(タップで飛ばしたとき)は 1 回だけ鳴らす
- つきつける音は、証拠品をつきつける行動を選んだ瞬間に鳴らす(`TrialScreen` の `choose`)
- BGM は、音ありならタイトル・事件の一覧・法廷などすべてのページでくり返し流す(`src/lib/bgm.ts`)
  - どのページにも出ている見出し(`HeaderNav`)から流す。ページを移っても曲は途切れず、頭にも戻らない
  - 音量は 0.35。要素を 1 つ使い回し、使う部品が消えて 400ms たったら止める(止めた所から再開)
  - ブラウザは操作の前の再生を止めるので、ページを開いた直後は鳴らず、最初のタップ・キー入力のあとに流れ始める
- BGM のファイルは曲を切らずに縮める: 前後の無音を削り、HE-AAC(32kbps・ステレオ)の `public/assets/audio/bgm.m4a`(約 390KB)にする
  - pre-commit の `check-added-large-files`(500KB)に収めるため。曲を途中で切るとくり返しの継ぎ目が不自然になるので、長さは保つ
  - 元の曲はフェードイン・フェードアウトするので、くり返しても継ぎ目は目立たない
  - macOS の `afconvert` で作る(前後の無音の削除は WAV にしてから行う)。HE-AAC を解けないブラウザでも、AAC の基本部分(音質は下がる)として鳴る
- 効果音と BGM の有無は見出しの「♪ 音あり / 音なし」でまとめて切り替え、`localStorage`(`llm-court:sound`)に覚えておく。既定は「音あり」

## 理由

- 合成なら素材のファイルを用意・管理しなくてよく、すべてオリジナルの音になる(既存作品の音を使わない)
- BGM はユーザーが用意したオリジナルの曲で、合成では代えられないのでファイルで持つ
- 静的ビルド・オフラインモードにも何も足さずに使える
- ブラウザは操作の前に音を出させないが、文字送りはタップ・クリックのあとに始まるので、そのとき AudioContext を作って再開すればよい

## 影響

- 判定・状態には関わらない表示だけの演出(イベントログ・オフラインの行動の列は変わらない)
- 音色を変えるときは `sound.ts` の数値を直す。効果音を音のファイルに差し替える場合はこの ADR を更新する
- BGM を差し替えるときは、同じ手順で 500KB 未満の `bgm.m4a` を作り直す
