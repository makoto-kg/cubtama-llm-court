# 0020: 最後の問いをやめ、判決を言い渡して閉廷する

- 日付: 2026-09-30
- 状態: 採用(ADR 0013 の「全矛盾を解いたら最後の問いに答えて閉廷する」を置き換える)

## 背景

これまでの裁判型は、全矛盾を解いたあと「最後の問い」(誰が・何を)に答えて閉廷していた。

ユーザーから次の要望があった。
- 最後の問いはカットする
- 代わりに、裁判官が判決を言い渡す
  - 刑罰は「3日間おやつ抜き」など、事件に合った内容にする
- そのあと被告が悲しむ台詞を言い、裁判のまとめを表示する

## 決定

- 進行(backend の `TrialEngine`・オフラインの `engine.ts` の両方)
  - 最後の矛盾を解いた時点で閉廷する(`TrialFinished(result="solved")`)
  - 最後の問いは出さない
  - ゲージが尽きたときの閉廷(`penalty`)は変えない
- 以前の記録との互換
  - 最後の問いの回答待ちで止まっているセッションは、これまでどおり答えて閉廷できる
    - 状態の `answering`、API の `POST /api/trials/{id}/answer`、CLI・評価の回答はそのために残す
  - オフラインの保存データにある「答える」行動は、閉廷済みなので読み飛ばす
- 事件に判決を持たせる(`Case.verdict` / `CaseVerdict`)
  - 刑罰(`sentence`)と、判決を聞いた被告の台詞(`defendant_reaction`)
  - 非公開の情報として扱う。閉廷後の解説(`Explanation.verdict`)で出す
  - 判決を持たない事件(生成した事件など)は、画面の定型文を使う
- 画面の流れ
  - 最後の矛盾を崩した応答と「証言崩壊!」のあと、「判決へ」で判決の場面に進む
  - 判決の場面(`VerdictSequence`。開廷の場面と同じ台本の仕組み)
    - 「判決」のカットイン
    - 裁判官が有罪を言い渡す(「有罪」のカットイン)
    - 裁判官が刑罰を言い渡す(木槌)
    - 被告の反応
    - 「閉廷」のカットイン
  - そのあと裁判のまとめを表示する
    - 結果と判決(有罪 — 刑罰)
    - 解いた矛盾、尋問の回数、残りのゲージ
    - 解説
  - 判決の場面は、その画面で閉廷したときだけ出す。閉廷後に開き直したときは、まとめだけを出す
- チュートリアルの判決
  - 刑罰: 3日間のおやつ抜き。それから、タマに毛づくろいでおわびすること
  - カブの反応を書いた

## 理由

- 被告だけが証言し嘘をつく形(ADR 0017)では、全矛盾を解けば犯人と真相は決まる。問いに答える手順は確認の繰り返しになっていた
- 判決と被告の反応で締めるほうが、法廷バトルとしての区切りがはっきりする
- 刑罰と反応は事件ごとの味付けなので、事件のデータに持たせる。LLM に書かせず、オフラインでも同じにする

## 影響

- 事件の `question` は事件生成と solver の検証には引き続き使う。プレイでは使わない
- 結果 `wrong_answer` は、以前のセッションでしか出ない
- 事件生成は、まだ判決(刑罰・被告の反応)を作らない。生成した事件では定型文になる
