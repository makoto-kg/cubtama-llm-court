# 0024: OGP(SNS で共有したときのカード)

- 日付: 2026-10-04
- 状態: 採用

## 背景

GitHub Pages で公開した(ADR 0021)ページの URL を SNS で共有すると、タイトル「llm-court」だけのそっけない表示になる。
ゲームのタイトルロゴ(ADR 0022)を使ったカードを出したい。
OGP の画像は絶対 URL が要るが、frontend は `output: "export"` の SPA で、配信先はビルド時の環境変数でしか分からない。

## 決定

- 画像は Next.js のファイル規約 `src/app/opengraph-image.jpg`(1200×630)に置く。`og:image`・`twitter:image` のタグはビルド時に自動で付く
  - `frontend/scripts/make_og_image.py` でタイトルロゴ・立ち絵(タマ検察官のつきつけ・カブ被告の動揺)・サブタイトルを合成して作る。手で描かない
  - pre-commit の上限(500KB)に収めるため JPEG にする
  - 代替テキストは `opengraph-image.alt.txt`
- `layout.tsx` の `metadata` に `openGraph`・`twitter`(`summary_large_image`)を書く。ページの `<title>` もゲーム名(`GAME_TITLE — GAME_SUBTITLE`)にそろえる
- `metadataBase` は環境変数 `NEXT_PUBLIC_SITE_URL`(配信先のオリジン。basePath は含めない)で渡す。未設定なら `http://localhost:3000`
  - workflow では `actions/configure-pages` の `origin` を渡す
  - ファイル規約の画像の URL には Next.js が basePath を付けるので、オリジンに basePath を含めると二重になる
- `og:url` は出さない(`metadataBase` に basePath を含めないため、相対で書くと basePath が抜ける)

## 理由

- ファイル規約なら画像の URL・サイズ・型のタグを手で書かずに済み、静的エクスポートでもそのまま出力される
- 合成をスクリプトにしておけば、ロゴや立ち絵を差し替えたときに作り直せる

## 影響

- ロゴ・立ち絵を変えたら `make_og_image.py` を実行し直す(サブタイトルの字は macOS のヒラギノ角ゴ W9 で描くので macOS で実行する)
- 配信先を変える(カスタムドメイン等)ときは `NEXT_PUBLIC_SITE_URL` も合わせる
