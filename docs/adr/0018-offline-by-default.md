# 0018: ビルドを 1 本にし、オフライン / オンラインを画面で選ぶ(既定はオフライン)

- 日付: 2026-09-29
- 状態: 採用(ADR 0014 のビルドの切り替えを置き換える)

## 背景

これまでのフロントエンドは、ビルド時の環境変数で画面を切り替えていた。
- 既定: バックエンドにつなぐオンラインの画面
  - タイトルでディベート・裁判を開廷する
  - 設定画面への導線がある
- `NEXT_PUBLIC_OFFLINE_ONLY=1`: オフラインの画面(同梱のパックで裁判を遊ぶ)

ユーザーから次の要望があった。
- ビルドを 1 本に統一する
- フロントエンドは SPA としてビルドする
- オフラインモードとオンラインモードを画面で選べるようにする
- オフラインモードを既定にする

## 決定

- ビルドは `pnpm build` の 1 本(SPA の静的エクスポート)
  - 画面を切り替える環境変数(`NEXT_PUBLIC_OFFLINE_ONLY` など)は使わない
- 遊び方のモードを画面で選ぶ(`src/lib/mode.ts`・`hooks/useAppMode.ts`)
  - タイトル(`/`)に「オフライン / オンライン」の切り替えを置く(`ModeSwitch`)
    - オフライン: 同梱の事件の一覧
    - オンライン: これまでのタイトル(ディベート・オンラインの裁判)
  - 見出しの「設定」は、オンラインのときだけ出す
  - 既定はオフライン
    - 静的ビルドの描画と最初の描画は、常にオフラインにする(ハイドレーションを揃えるため)
  - 選んだモードは閲覧者のブラウザ(`localStorage` の `llm-court:mode`)に覚えておく
    - 保存できない環境でも、開いている間は選んだモードを保つ
- オフラインのときは API を呼ばない。オンラインの画面(`/court/`・`/trial/`・`/settings/`)のページは常にビルドに含まれる

## 理由

- 1 本のビルドなら、配布物と開発時の画面が一致し、切り替えの手順を覚えなくてよい
- バックエンドや LLM サーバーがなくても、開いてすぐ遊べるほうが既定としてよい
- モードは閲覧者ごとの好みなので、ブラウザに覚えておく程度で十分。失われても既定(オフライン)に戻るだけ

## 影響

- `NEXT_PUBLIC_OFFLINE_ONLY=1` は廃止した。指定しても何も変わらない
- オンラインで遊ぶには、`llm-court serve` を起動し、タイトルで「オンライン」を選ぶ
- オンラインを選んだ状態でバックエンドが起動していなければ、これまでどおり「API に接続できません」と表示する
